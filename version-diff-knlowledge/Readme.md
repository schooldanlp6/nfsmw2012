# Versions that are targeted for the Decomp (and why they matter)
(lowest to highest interest)
## PS3 (and Xbox360)
these versions should in theory not differ and would both be interested for the decomp as they are the oldest version (however they are not having any specific or interesting features aside from high quality assets over PSVita (however likely lower quality then PC)
## PC
newest of them with HQ assets and a lot of additions as well as DLCs etc.
## PSVita
The PSVita uses a special rendering engine which would be desirable to understand if we want to run NFSMW2012 on lower power hardware
## WiiU
(Yes the console everyone hates): Depsite its hate however it seems to be the console with the by far most features like Co-Driving,Cheat Menu (e.g. Day Night switching etc.) - It is PowerPC however.
